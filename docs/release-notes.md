Creator Desk is a local workspace for importing channel reports and reviewing analytics.

Downloads:
- mac-arm64: Apple Silicon Macs, DMG installer and ZIP.
- mac-x64: Intel Macs, DMG installer and ZIP.
- windows-x64-Setup.exe: Windows installer; ZIP is also available.
- linux-x64.deb: Debian/Ubuntu x64 package.

Each platform package passes unit tests, static checks, and installed-application tests before publication. SHA256SUMS.txt contains download checksums.

macOS builds are ad hoc signed and are not notarized. Windows builds are unsigned. Operating systems may display publisher warnings.

This version supports local CSV/JSON imports, persistent workspaces, dashboards, and backups. Live YouTube integration remains in development.
